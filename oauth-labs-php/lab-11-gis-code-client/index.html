GIS Code Client (auth code)

Google Identity Services — Code model. Gets an authorization code via storagerelay + postMessage, then server exchanges it for tokens.

1. google.accounts.oauth2.initCodeClient()
2. codeClient.requestCode() opens popup
3. Google uses storagerelay + postMessage internally
4. Callback receives { code }
5. Client POSTs code to api/exchange.php
6. PHP exchanges code → access_token + id_token
7. PHP fetches user profile
