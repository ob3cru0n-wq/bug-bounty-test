Lab 07

Implicit + popup + postMessage

OAuth 2.0 Implicit flow via popup window. Token returned in URL fragment, sent back via postMessage.

1. Main window opens popup → Google auth
2. Google redirects popup to callback.html#access_token=...
3. Callback reads fragment, calls postMessage(token)
4. Main window receives token, calls api/userinfo.php
5. PHP fetches profile with access_token
