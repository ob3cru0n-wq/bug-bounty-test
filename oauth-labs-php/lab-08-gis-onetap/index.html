GIS One Tap (FedCM) + renderButton

Google Identity Services — One Tap prompt via FedCM + rendered sign-in button. Returns JWT credential.

1. Page loads GSI client library
2. google.accounts.id.initialize() with callback
3. google.accounts.id.prompt() shows One Tap
4. renderButton() as fallback
5. Callback receives credential (JWT)
6. POST to api/verify.php → PHP validates JWT
